# AI Finance Expense Categorizer

My first AI automation project that categorizes banking transactions using Gemini AI and generates a clean Excel report.

## Features

- Read transaction data from CSV
- Categorize transactions using Gemini AI
- Use structured JSON output with Pydantic
- Handle large datasets using batching
- Create summary tables
- Export results to Excel
- Generate visual charts
